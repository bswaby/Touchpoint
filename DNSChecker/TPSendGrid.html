SendGrid DNS Checker

Checks all four SendGrid records for your church domain, shows which ones are done, and tells you exactly how to fix the rest. Runs in your browser using public DNS from Google and Cloudflare. Nothing is stored.

Advanced

How to add the records

  1. Log in where your domain's DNS is managed. Usually where you bought the domain (GoDaddy, Namecheap, Squarespace, Network Solutions) or Cloudflare. Look for DNS or Manage DNS.
  2. Add each record from your SendGrid screen using only the first part of the name. Your DNS host adds your domain for you.
    TypeHost / NameValue
    CNAMEem1234value from SendGrid
    CNAMEs1._domainkeyvalue from SendGrid
    CNAMEs2._domainkeyvalue from SendGrid
    TXT_dmarcv=DMARC1; p=none;
  3. Never type your full domain in the Host field, and never use @ for these records.
  4. Some hosts (like Network Solutions) need a period at the end of CNAME values, like u12345.wl123.sendgrid.net. If this checker says your domain was added to the end of a value, that is the fix.
  5. If a _dmarc TXT record already exists, keep it and skip that row. Two DMARC records break DMARC.
  6. On Cloudflare, set each CNAME to DNS only (gray cloud), not Proxied.
  7. Wait 30 to 60 minutes, then run this checker and click Verify in SendGrid.
