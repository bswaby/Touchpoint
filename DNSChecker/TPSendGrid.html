SendGrid DNS Checker

Checks your church domain's SendGrid records and tells you exactly what to fix. Runs in your browser using public DNS from Google and Cloudflare. Nothing is stored.

How to add the records

  1. Log in where your domain's DNS is managed. Usually where you bought the domain (GoDaddy, Namecheap, Squarespace) or Cloudflare. Look for DNS or Manage DNS.
  2. Add each record from your SendGrid screen using only the first part of the name. Your DNS host adds your domain for you.
    TypeHost / NameValue
    CNAMEem1234value from SendGrid
    CNAMEs1._domainkeyvalue from SendGrid
    CNAMEs2._domainkeyvalue from SendGrid
    TXT_dmarcv=DMARC1; p=none;
  3. Never type your full domain in the Host field, and never use @ for these records.
  4. If a _dmarc TXT record already exists, keep it and skip that row. Two DMARC records break DMARC.
  5. On Cloudflare, set each CNAME to DNS only (gray cloud), not Proxied.
  6. Wait 30 to 60 minutes, then run this checker and click Verify in SendGrid.
